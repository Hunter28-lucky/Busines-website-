## 💡 Customization Quick Guide

### Change Colors
Find and replace throughout project:
```tsx
blue-600 → your-color-600
purple-600 → your-color-600
```

### Update Company Name
Files: `components/Navbar.tsx`, `components/Footer.tsx`
```tsx
<span className="text-blue-600">Your</span>
<span className="text-gray-900">Company</span>
```

### Edit Services
File: `app/services/page.tsx`
Update the services array

### Modify Pricing
File: `app/pricing/page.tsx`
Update the pricingPlans array

### Add Portfolio Items
File: `app/portfolio/page.tsx`
Add to portfolio array

### Update Testimonials
File: `app/testimonials/page.tsx`
Add to testimonials array
